# FormSaathi AI 🎓

**Your AI-Powered Scholarship Application Assistant**

FormSaathi AI is an AI-powered web application designed to help students understand scholarship guidelines and prepare their applications easily.

## 🚀 Live Demo
https://formsaathi-ai-d2vgqmbbegtlfb3tjuj4qd.streamlit.app/

## ✨ Features
- Upload and analyze scholarship PDF documents.
- Generate AI-powered document summaries.
- Find required application documents.
- Extract important dates and deadlines.
- Check student eligibility using profile details.
- Get application readiness guidance.
- Chat with AI about uploaded documents.
- Download application reports.

## 🛠️ Technologies Used
- Python
- Streamlit
- Google Gemini AI
- PyPDF

## 💻 Run Locally

1. Clone this repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Configure your Gemini API key in Streamlit secrets.
4. Run the application:

   `python -m streamlit run app.py`

## 🎯 Project Goal
To make scholarship application preparation easier, faster, and more accessible for students.
